# BUG-04: Буруу JSON биетэй POST /api/books хүсэлтэд 400 биш 200 OK буцаана

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 155.0.8059.85, Windows (апп WSL2 Ubuntu дээр, node v23.11.0), 2026-10-20

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. `node app.js` шинээр асаана.
2. Өөр терминалд дараахыг ажиллуулна:

```
curl -i -X POST localhost:3000/api/books -d 'буруу оролт'
```

3. Хариуны эхний мөр (статус)-ийг харна.
4. Браузераар http://localhost:3000 нээж (эсвэл шинэчилж) хүснэгтийг харна.

Хүлээгдэж байсан: Буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана (спецификац: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана»).

Бодит үр дүн: `HTTP/1.1 200 OK` ба `{"result":"OK"}` буцна. Мөн хуудсыг шинэчилсний дараа хүснэгтэд хоосон гарчигтай, он 0 бүхий нэг шинэ ном нэмэгдсэн байна.

Ноцтой байдал: Major - API буруу оролтыг амжилттай гэж хүлээн авч, өгөгдөлд хоосон бичлэг үүсгэнэ.

Хавсралт: [evidence/bug-04-curl.txt](../evidence/bug-04-curl.txt) - `curl -i`-ийн бүтэн гаралт (HTTP/1.1 200 OK статусын мөртэй)

Олдсон аялал: Saboteur (API түвшний довтолгоо)
